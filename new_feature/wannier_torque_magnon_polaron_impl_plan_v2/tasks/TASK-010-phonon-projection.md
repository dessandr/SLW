# TASK-010 - Phonon Projection

## Goal

Project Cartesian kernels onto zero-point phonon modes and support direct mode-g kernels.

## Dependencies

TASK-005, TASK-008.

## Tests

Cartesian/mode agreement, rephasing, acoustic translation, imaginary-mode warning, and unit consistency.

## Done when

No zero-point factor is applied twice and all modes retain explicit normalization provenance.
