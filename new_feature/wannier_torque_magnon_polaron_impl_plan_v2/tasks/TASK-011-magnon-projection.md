# TASK-011 - External Magnon BdG Projection

## Goal

Transform `V_pi_ph` into external magnon modes and extract normal/anomalous blocks.

## Dependencies

TASK-004, TASK-010.

## Tests

One-sublattice circular combination, two-sublattice AFM frames, paraunitarity, rephasing, degenerate-subspace invariants, and explicit failure with an extra metric.

## Done when

The output is directly consumable by the existing magnon-polaron solver.
