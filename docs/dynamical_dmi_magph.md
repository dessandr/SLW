# Dynamical DMI-Induced Magnon-Phonon Hybridization

This note defines the working theory for magnon-phonon hybridization generated by
phonon-induced, or dynamical, Dzyaloshinskii-Moriya interaction (DMI).

## 1. Spin Hamiltonian

Use the tensor-exchange Hamiltonian in the TB2J convention

```text
H_spin = - sum_{ijR} S_i^a J_{ij}^{ab}(R; u) S_j^b .
```

The exchange tensor is decomposed as

```text
J_{ij}^{ab}(R) =
  J_iso,ij(R) delta_ab
  + Gamma_{ij}^{ab}(R)
  + J_DMI,ij^{ab}(R),
```

where

```text
J_DMI^{ab} = epsilon_abc D^c
```

with the matrix convention

```text
J_DMI =
[[ 0,  Dz, -Dy],
 [-Dz,  0,  Dx],
 [ Dy, -Dx,  0]].
```

Then

```text
- S_i^a J_DMI^{ab} S_j^b = - D_ij . (S_i x S_j).
```

## 2. Phonon-Induced Exchange Tensor

Expand the exchange tensor to first order in atomic displacement:

```text
J_{ij}^{ab}(R; u) =
J_{ij}^{ab}(R)
+ sum_{kappa mu Rp}
  dJ_{ij,kappa mu}^{ab}(R,Rp) u_{kappa mu}(Rp),
```

with

```text
dJ_{ij,kappa mu}^{ab}(R,Rp)
= partial J_{ij}^{ab}(R) / partial u_{kappa mu}(Rp).
```

The DMI part is

```text
dJ_DMI^{ab} = epsilon_abc dD^c,
```

so the dynamical-DMI magnon-phonon Hamiltonian is

```text
H_mp^DMI =
- sum_{ijR,kappa mu Rp}
  dD_{ij,kappa mu}(R,Rp) . (S_i x S_j) u_{kappa mu}(Rp).
```

This is the central object produced by the `dDMI_r` component of the
`compute_dJ_epr_tensor` output.

## 3. Symmetry Interpretation

A static crystal symmetry may forbid a static DMI on a bond.  A phonon mode can
still generate a nonzero dynamical DMI if its displacement pattern breaks the
bond symmetry that forbids the DMI.

Equivalently, for a normal mode `Q_{q nu}`,

```text
partial D_ij / partial Q_{q nu}
```

is nonzero only when the product of the phonon-mode representation and the DMI
axial-vector representation contains the symmetry channel of the bond spin
chirality `S_i x S_j`.

Therefore:

- Not every phonon mode produces a dynamical DMI.
- Modes that preserve the DMI-forbidding local symmetry give zero or symmetry-cancelled coupling.
- Modes that instantaneously break inversion, mirror, or other local symmetries can allow
  one-magnon-one-phonon hybridization.
- A nonzero `dDMI` with `lambda_SOC != 0` but zero `dDMI` in the collinear/SOC-off limit
  is the expected behavior.

## 4. Linear Spin-Wave Expansion

Let the ordered spin direction on site `i` be

```text
S_i^0 = S eta_i n,
```

where `eta_i = +1` or `-1` for collinear sublattices.  Write

```text
S_i = S eta_i n + delta S_i.
```

To linear order in the magnon fluctuation,

```text
S_i x S_j =
S eta_i n x delta S_j
+ S eta_j delta S_i x n
+ O(delta S^2).
```

Thus the one-magnon-one-phonon dynamical-DMI term is

```text
H_mp,DMI^(1) =
- S sum dD_ij . [
    eta_i n x delta S_j
  + eta_j delta S_i x n
  ] u.
```

This is why dynamical DMI directly produces a linear magnon-phonon
hybridization channel.  It couples one transverse spin fluctuation to one
phonon displacement.

By contrast, the isotropic exchange derivative

```text
dJ_iso S_i . S_j u
```

usually contributes mainly to phonon plus two-magnon vertices in a collinear
state.  Linear terms from isotropic exchange cancel or vanish in many
equilibrium collinear cases because the transverse fluctuation is perpendicular
to the ordered moment.

## 5. Local Transverse Basis

For each magnetic site define a local orthonormal frame

```text
(e_i1, e_i2, e_i3),  e_i3 = eta_i n.
```

The transverse fluctuation is

```text
delta S_i =
sqrt(S/2) [ e_i,+ a_i + e_i,- a_i^dagger ],
```

with

```text
e_i,+ = e_i1 - i e_i2,
e_i,- = e_i1 + i e_i2.
```

The real-space linear DMI vertex has contributions from both ends of the bond:

```text
V_{i,j;kappa mu}^{DMI}
~ - sqrt(S/2) [
    eta_j dD_ij . (e_i,+ x n)
  + eta_i dD_ij . (n x e_j,+)
  ] u_{kappa mu}.
```

The exact sign and conjugation convention must follow the magnon Nambu basis
used in the LSWT kernel.

## 6. Fourier Transform

Use

```text
u_{kappa mu}(Rp) =
sum_{q nu}
sqrt(hbar / (2 M_kappa omega_{q nu}))
e_{kappa mu}^{nu}(q)
(b_{q nu} + b_{-q nu}^dagger)
exp(i q . Rp),
```

and

```text
a_i(Rl) = 1/sqrt(N) sum_k a_{i k} exp(i k . (Rl + tau_i)).
```

The dynamical-DMI vertex becomes a site-basis magnon-phonon coupling

```text
H_mp,DMI^(1) =
sum_{k q nu}
Psi_{k+q}^dagger V_DMI(k,q,nu) Phi_q + h.c.,
```

where `Psi_k` is the magnon Nambu spinor and `Phi_q` is the phonon Nambu
coordinate or phonon creation-annihilation basis, depending on implementation.

## 7. Magnon BdG Transformation

The site-basis magnon Nambu spinor is transformed to magnon-band basis by the
paraunitary BdG matrix:

```text
Psi_k = U_k Alpha_k.
```

For bosonic BdG, the metric must be retained:

```text
U_k^dagger eta U_k = eta,
eta = diag(+1...+1,-1...-1).
```

Any magnon-phonon vertex transformed into the band basis must use the same
Nambu ordering and metric convention as the magnon Hamiltonian diagonalization.
Schematically,

```text
g_DMI(k,q,nu) = U_{k+q}^{-1} V_DMI(k,q,nu) F_{q nu},
```

where `F_{q nu}` contains the phonon eigenvector and mass-frequency
normalization.  In code this should be implemented with the same inverse or
metric-adjoint convention already used for the magnon BdG solver.

## 8. Expected Numerical Checks

1. SOC-off limit:

```text
lambda_SOC = 0  =>  dDMI ~ 0
```

up to numerical noise.

2. SOC scaling:

```text
dDMI(lambda) roughly scales with lambda
```

for small `lambda`.

3. Directed-bond antisymmetry:

```text
D_ij(R) ~= -D_ji(-R)
dD_ij(R,Rp) ~= -dD_ji(-R,Rp')
```

with the correct transformed displacement cell and component.

4. Mode selection:

After projection onto phonon eigenmodes, only modes whose displacement pattern
breaks the relevant DMI-forbidding symmetry should show strong hybridization.

5. Hybridization signature:

Near a magnon-phonon crossing, nonzero dynamical DMI should open an avoided
crossing or produce spectral-weight mixing in the one-magnon-one-phonon sector.

## 9. Implementation Targets

The `compute_dJ_epr_tensor` output needed by the dynamical-DMI channel is:

```text
/dDMI_r/m{target}_b{bond}
```

with shape

```text
(nRp, n_disp_axes, 3)
```

and unit `meV/A`.

The implementation should:

1. Read `dDMI_r`, bond metadata, target atoms, displacement axes, and `Rp`.
2. Project Cartesian displacements onto phonon eigenvectors.
3. Build the real-space linear spin-fluctuation vertex from
   `- dD . (S_i x S_j) u`.
4. Fourier transform to `(k,q)`.
5. Transform from site magnon basis to BdG magnon-band basis with the bosonic
   metric convention.
6. Add this vertex as a one-magnon-one-phonon hybridization term.
